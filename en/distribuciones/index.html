What is a probability distribution?

A probability distribution describes how probability is spread across the possible values of a random variable. It lets us quantify which outcomes are most likely, which are rare, and how a phenomenon behaves on average and in terms of variability.

Density function (PDF), mass function (PMF) and cumulative distribution function (CDF)

For continuous variables the probability density function (PDF) is used — it does not give point probabilities directly, but probability density around an interval. For discrete variables the probability mass function (PMF) assigns a probability to each individual value.

The cumulative distribution function (CDF) applies to both cases and gives the cumulative probability up to a value x: \(P(X \le x)\). It is essential for computing tails, intervals and percentiles.

Continuous vs. discrete distributions

Discrete distributions: model integer counts (e.g. number of successes or events).
Continuous distributions: model measurable quantities on a real scale (e.g. times, lengths or measurement errors).

Brief description of each distribution

  • Normal: continuous, symmetric, bell-shaped; the foundation of many models via the central limit theorem.
  • Binomial: discrete; number of successes in n independent trials with constant probability p.
  • Poisson: discrete; count of events in an interval when they occur at a constant average rate.
  • Student's t: continuous; like the normal but with heavier tails, useful with small samples and unknown variance.
  • Chi-square: continuous and non-negative; widely used in inference about variances and goodness-of-fit / independence tests.
  • F (Fisher–Snedecor): continuous and non-negative; ratio of variances, central to ANOVA and model comparison.
  • Exponential: continuous; models waiting times between events in a Poisson process.
  • Uniform: continuous; all values within an interval have the same density.
  • Gamma: continuous and positive; generalises the exponential and models aggregated waiting times.
  • Beta: continuous on [0,1]; very useful for proportions and probabilities.
  • Lognormal: continuous and positive; arises when the logarithm of the variable follows a normal.
  • Weibull: continuous and positive; common in reliability and survival / lifetime analysis.
  • Negative binomial: discrete; number of failures before observing a given number of successes.
  • Geometric: discrete; number of trials until the first success.
  • Hypergeometric: discrete; sampling without replacement from a finite population.
  • Bernoulli: discrete binary; a single trial with success (1) or failure (0).

How to choose a probability distribution

Start by identifying whether your variable is discrete or continuous. If you are counting successes in a fixed number of trials, use the binomial; if counting events in an interval with a stable rate, use Poisson; if working with continuous measurements around a mean, the normal is usually the starting point.

Discrete data

Counts, successes/failures, defects, arrivals or draws without replacement.

Continuous data

Measurements, waiting times, positive amounts, modelled proportions or transformed variables.
