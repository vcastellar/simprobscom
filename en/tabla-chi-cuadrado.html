See all tables

Tabulated area:
How to read the table: pick the row for the degrees of freedom ν and the column for the area. With right tail (the default, and the convention used by most textbooks), each column is the area α = P(X > χ²) to the right of the value; this is what goodness-of-fit and independence tests need. For example, at the 5% level with ν = 10: column α = 0.05 → χ² = 18.30704. With left tail, each column is the cumulative probability p = P(X ≤ χ²). The cell values are the same in both views; only the column label changes (p = 1 − α).

What this table is for

  • Goodness of fit (ν = k − 1, with k categories) and independence in contingency tables (ν = (r − 1)(c − 1)): the right tail is used. Run the full goodness-of-fit test or test of independence.
  • Variance of a normal population (ν = n − 1): test and confidence interval. The interval uses two values from the table, one from each tail.

How to use these tables

Chi-Square Distribution

If Z₁, Z₂, …, Zᵥ are independent standard normal variables, then X = Z₁² + … + Zᵥ² follows a chi-square distribution with ν degrees of freedom. Its density function is:

\( f(x,\nu) = \dfrac{x^{\nu/2-1}\,e^{-x/2}}{2^{\nu/2}\,\Gamma(\nu/2)}, \quad x \geq 0 \)

The mean is ν and the variance is 2ν.

Critical values table

Shows the chi-square critical values for each number of degrees of freedom ν. The Tabulated area switch sets how the columns are labelled:

  • Right tail (default): each column is α = P(X > χ²). This is the usual textbook layout, because chi-square tests reject for large values. Example: test at 5%, ν = 5 → column α = 0.05 → χ² = 11.07050.
  • Left tail: each column is the cumulative probability p = P(X ≤ χ²), the convention of some manuals and of functions such as R's qchisq. The same value 11.07050 is in column p = 0.95.

Main uses
  • Goodness-of-fit test
  • Test of independence in contingency tables
  • Variance estimation and confidence intervals for σ²
  • Homogeneity tests
