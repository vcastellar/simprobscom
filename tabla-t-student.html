Tipo de contraste:
Cómo leer la tabla: elige el tipo de contraste, la fila de los grados de libertad ν y la columna del nivel de significación α. Con dos colas (test bilateral, opción por defecto) cada columna es α = P(|T| > t): el área se reparte a partes iguales entre ambos extremos. Con una cola (test unilateral) cada columna es α = P(T > t), el área a la derecha; para la cola izquierda usa −t. Las celdas son las mismas en las dos vistas, porque α (dos colas) = 2 × α (una cola). Ejemplo: con ν = 10, un test bilateral al 5 % (columna α = 0.05 de dos colas, o α = 0.025 de una cola) da t = 2.22814.

Para qué sirve esta tabla

  • Intervalos de confianza para la media cuando no se conoce σ: x̄ ± t·s/√n, con ν = n − 1 grados de libertad. Calcular el intervalo.
  • Contrastes t: de una media (ν = n − 1), de medias apareadas (ν = n − 1, con n pares) y de dos medias (ν = n₁ + n₂ − 2 si las varianzas son iguales).
  • Una o dos colas: en un contraste bilateral al 5 %, el valor crítico está en la columna α = 0,05 de dos colas, que es la misma que α = 0,025 de una cola.

Cómo usar estas tablas

Distribución t de Student

La distribución t de Student con ν grados de libertad tiene función de densidad:

\( f(t,\nu) = \dfrac{\Gamma\!\left(\tfrac{\nu+1}{2}\right)}{\sqrt{\nu\pi}\;\Gamma\!\left(\tfrac{\nu}{2}\right)} \left(1+\dfrac{t^2}{\nu}\right)^{-\frac{\nu+1}{2}} \)

Conforme ν → ∞ la distribución converge a la Normal estándar N(0,1).

Tabla de valores críticos

Muestra los valores críticos t para cada grado de libertad ν. El selector Tipo de contraste decide cómo se etiquetan las columnas:

  • Dos colas (por defecto): cada columna es α = P(|T| > t), el área repartida entre ambos extremos. Es la que necesitas en un contraste bilateral o en un intervalo de confianza. Ejemplo: α = 0.05, ν = 20 → t = 2.08596.
  • Una cola: cada columna es α = P(T > t), el área a la derecha, para contrastes unilaterales. El mismo 2.08596 aparece en la columna α = 0.025, porque α (dos colas) = 2 × α (una cola).
  • Cuando ν = ∞ los valores coinciden con los cuantiles de la Normal estándar.

Una cola o dos colas: ejemplo con ν = 20 y α = 0,05

Supón un contraste sobre una media con una muestra de n = 21 observaciones, de modo que ν = n − 1 = 20 grados de libertad, y un nivel de significación α = 0,05. El valor crítico depende de la hipótesis alternativa:

  • Dos colas (H₁: μ ≠ μ₀): el 5 % se reparte entre ambos extremos, 2,5 % en cada uno. Con la vista de dos colas, busca la columna α = 0.05 (en la vista de una cola es α = 0.025) en la fila 20 → t = 2.08596. Rechazas H₀ si |tobs| > 2.08596.
  • Una cola, derecha (H₁: μ > μ₀): todo el 5 % queda en la cola derecha. Con la vista de una cola, busca la columna α = 0.05 en la fila 20 → t = 1.72472. Rechazas H₀ si tobs > 1.72472.
  • Una cola, izquierda (H₁: μ < μ₀): por simetría, el valor crítico es −1.72472. Rechazas H₀ si tobs < −1.72472.

Con el mismo α, el valor crítico de dos colas es siempre mayor que el de una cola, porque cada extremo recibe solo la mitad del área. Confundir las dos vistas es el error más habitual al usar la tabla t.

Tabla de distribución acumulada

Cada celda muestra P(T ≤ t) para el número de grados de libertad seleccionado. Para calcular p-valores bilaterales: p = 2 · P(T > |tobs|) = 2 · (1 − P(T ≤ |tobs|)).

Preguntas frecuentes

  • ¿Cómo se lee la tabla t de Student? Elige si el contraste es de dos colas (bilateral) o de una cola (unilateral), y busca la fila del grado de libertad ν y la columna del nivel de significación α: la celda es el valor crítico t. Ejemplo: ν = 10 y α = 0,05 dan t = 2,228 con dos colas y t = 1,812 con una cola.
  • ¿Cuándo se usa la tabla t en lugar de la tabla normal? Con muestras pequeñas y varianza poblacional desconocida se usa la tabla t de Student; al crecer los grados de libertad, la t se aproxima a la tabla normal estándar.
  • ¿Qué diferencia hay entre una cola y dos colas? Una cola deja toda el área α a un lado (P(T > t) = α); dos colas la reparten entre ambos extremos (P(|T| > t) = α), por lo que el valor crítico es mayor.
